# shu-lamp

Plano técnico interactivo de una ampolleta con ESP32 y micrófono.

Abre `index.html` en el navegador: es una hoja de medidas que redibuja la lámina (vista frontal explosionada, corte A–A y vista inferior) a medida que ingresas valores tomados con pie de metro. Verifica además si la fuente, el micrófono y la placa ESP32 caben dentro del cuerpo.
